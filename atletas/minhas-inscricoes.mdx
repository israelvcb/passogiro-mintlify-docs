# Minhas Inscrições

## Acessando suas inscrições

1. Faça login em [passogiro.com.br](https://passogiro.com.br)
2. Clique no seu nome ou avatar no canto superior direito
3. Selecione **Minhas Inscrições**

## Status das inscrições

| Status | Significado |
|--------|-------------|
| **Aguardando pagamento** | Inscrição criada, pagamento pendente |
| **Pago** | Pagamento confirmado, inscrição ativa |
| **Cortesia** | Inscrição gratuita (cupom 100%) — confirmada sem pagamento |
| **Cancelado** | Inscrição cancelada |
| **Reembolsado** | Valor devolvido ao atleta |
| **Expirado** | Prazo de pagamento encerrado sem confirmação |

## Ações disponíveis

### Pagar inscrição pendente

Se sua inscrição está com status **Aguardando pagamento**:

1. Clique na inscrição
2. Clique em **Pagar agora**
3. Escolha a forma de pagamento e finalize

O PIX tem prazo de **30 minutos** para pagamento após geração. Após expirar, você pode gerar um novo código na mesma tela.

### Ver detalhes da inscrição

Clique em qualquer inscrição para ver:
- Evento, data e local
- Categoria escolhida
- Número do atleta (dorsal), quando atribuído
- Status do pagamento
- QR Code de check-in (disponível após confirmação)

### Baixar comprovante

Na página de detalhes, clique em **Baixar comprovante** para salvar um PDF com os dados da inscrição.

### QR Code de check-in

Após a confirmação do pagamento, um **QR Code único** é gerado para sua inscrição. Use-o no check-in presencial do evento.

<Tip>
Salve uma imagem do QR Code no seu celular para o dia do evento — funciona mesmo sem internet.
</Tip>

## Troca de categoria

Alguns eventos permitem trocar de categoria antes da data limite. Quando disponível:

1. Acesse os detalhes da inscrição
2. Clique em **Trocar categoria**
3. Selecione a nova categoria
4. Pague a diferença de valor (se houver)

Veja as regras completas em [Troca de Categoria](/sistema/troca-categoria).
