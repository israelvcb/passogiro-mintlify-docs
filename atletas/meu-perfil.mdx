# Meu Perfil

## Acessando o perfil

1. Faça login em [passogiro.com.br](https://passogiro.com.br)
2. Clique no seu nome ou avatar no canto superior direito
3. Selecione **Meu Perfil**

## Dados pessoais

| Campo | Editável | Observação |
|-------|----------|------------|
| Nome completo | Sim | |
| E-mail | Não | Contate o suporte para alterar |
| CPF | Não | Contate o suporte para corrigir erros |
| Data de nascimento | Não | Contate o suporte para corrigir erros |
| Telefone | Sim | |
| Endereço | Sim | |
| Gênero | Sim | |
| Foto de perfil | Sim | |

<Warning>
CPF e data de nascimento não podem ser alterados diretamente para evitar fraudes. Se houver erro, entre em contato com o suporte.
</Warning>

## Alterando a senha

1. Acesse **Meu Perfil**
2. Clique em **Alterar senha**
3. Informe a senha atual e a nova senha (duas vezes)
4. Clique em **Salvar**

## Preferências de notificação

Configure quais comunicações deseja receber:

- **E-mail de confirmação de inscrição** — sempre enviado
- **Lembretes de evento** — enviados 7 dias e 1 dia antes do evento
- **Novidades e promoções** — opt-in, desativado por padrão

## Excluir conta

Para solicitar a exclusão da conta e dos dados pessoais (conforme LGPD), entre em contato com [suporte@passogiro.com.br](mailto:suporte@passogiro.com.br). O processo leva até 15 dias úteis.

<Info>
Contas com inscrições ativas em eventos futuros não podem ser excluídas imediatamente.
</Info>
