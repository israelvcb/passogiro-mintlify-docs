# Bem-vindo, Organizador

O Passo Giro oferece uma plataforma completa para organizar eventos esportivos — desde a criação do evento até o check-in no dia e o saque dos valores arrecadados.

## Fluxo completo de um evento

```
Criar evento → Configurar categorias → Definir preços
     ↓
Configurar cupons → Cadastrar locais de kit → Abrir inscrições
     ↓
Gerenciar inscrições → Atribuir dorsais → Exportar lista
     ↓
Check-in no evento → Retirada de kit → Sacar recebimentos
```
