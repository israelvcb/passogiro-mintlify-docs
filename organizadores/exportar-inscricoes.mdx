# Exportar Inscrições

## Como exportar

1. No painel do evento, acesse **Inscritos**
2. Aplique os filtros desejados (opcional)
3. Clique em **Exportar**
4. Selecione o formato: **Excel (.xlsx)** ou **CSV**
5. O download começa automaticamente

## Dados incluídos na exportação

A planilha exportada contém as seguintes colunas:

| Coluna | Descrição |
|--------|-----------|
| ID | Identificador único da inscrição |
| Nome | Nome completo do atleta |
| CPF | CPF do atleta |
| E-mail | E-mail de contato |
| Telefone | Telefone cadastrado |
| Data de nascimento | |
| Gênero | |
| Categoria | Categoria inscrita |
| Modalidade | |
| Dorsal | Número atribuído |
| Camiseta | Tamanho selecionado |
| Status | Status atual da inscrição |
| Forma de pagamento | PIX ou Cartão |
| Valor pago | Valor total pago pelo atleta |
| Valor líquido | Valor que o organizador recebe |
| Cupom | Código do cupom utilizado |
| Data da inscrição | Data e hora da inscrição |
| Data do pagamento | Data e hora da confirmação do pagamento |
| Check-in | Se realizou check-in |
| Kit retirado | Se retirou o kit |
| Endereço completo | Cidade, estado do atleta |

## Exportação filtrada

Se você aplicou filtros no painel antes de exportar, apenas as inscrições filtradas são incluídas. Isso permite, por exemplo:

- Exportar apenas inscrições **pagas** da categoria **10km Feminino**
- Exportar apenas atletas que **não fizeram check-in**
- Exportar inscrições que usaram determinado **cupom**

## Exportação completa

Para exportar **todas** as inscrições sem filtros, certifique-se de que nenhum filtro está ativo antes de clicar em exportar.

## Uso dos dados exportados

Usos comuns da planilha exportada:
- Envio à empresa de cronometragem
- Preparação dos envelopes/kits por número
- Lista de conferência na retirada de kit
- Relatório de participação para patrocinadores
